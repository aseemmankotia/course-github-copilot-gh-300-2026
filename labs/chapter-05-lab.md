# Chapter 5 Lab: How GitHub Copilot Works and Handles Data

**Estimated time:** 15 minutes

## Exercise

Review a captured sample request/response trace showing what context (open file, cursor position) is sent to Copilot, and identify what is NOT included

## Key takeaway

Copilot's suggestions come from a bounded, context-driven request — know precisely what is sent, filtered, and retained at each stage.
