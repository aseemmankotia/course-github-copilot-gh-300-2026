# Chapter 7 Lab: Developer Use Cases for AI Pair Programming

**Estimated time:** 20 minutes

## Exercise

Use Copilot Chat to refactor a nested callback function into async/await, then generate a commit message and README section for the change

## Key takeaway

Match each development task — generation, refactor, explain, translate, document — to the Copilot workflow built for it, and know where human judgment stays essential.
