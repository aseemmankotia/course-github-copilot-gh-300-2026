# Chapter 2 Lab: Copilot in the IDE: Completions, Chat, Inline Chat, and Slash Commands

**Estimated time:** 20 minutes

## Exercise

In VS Code, open Copilot Chat, run /explain on a selected function, then /tests to generate unit tests, and use inline chat (Ctrl+I) to refactor a method

## Key takeaway

Pick the right in-editor surface — completions, Chat, inline chat, or a slash command — based on scope: whole-file exploration vs. a quick localized edit.
