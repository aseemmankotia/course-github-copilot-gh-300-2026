# Chapter 3 Lab: Copilot in the CLI, GitHub.com, Pull Requests, and Extensions

**Estimated time:** 20 minutes

## Exercise

Install the GitHub CLI Copilot extension, run gh copilot suggest for a git command, then open a pull request on GitHub.com and review the Copilot-generated PR summary

## Key takeaway

Copilot extends beyond the editor into the CLI, GitHub.com, and pull requests — know which surface and plan tier each capability requires.
